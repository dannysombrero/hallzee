# Contributing to Hallzee

Please start with an issue for substantial changes. Keep student data,
credentials, private keys, local databases, and exported CSV files out of the
repository. See `docs/testing-and-installation.md` for supported setup and
validation commands.

Pull requests should explain the user-visible change, include relevant
documentation updates, and pass the appropriate GitHub Actions checks. Do not
include real classroom data in fixtures, screenshots, logs, or examples.
