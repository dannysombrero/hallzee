# Hallzee terminal banner variants

Three wide photographic variants for the [build guide](../../build-your-own-terminal.md), generated with the built-in image generation tool from the supplied prototype photograph. Each PNG is 1942 × 809 pixels (approximately 2.4:1).

- [Wide workbench](01-wide-workbench.png): closest to the original photograph; recommended for the guide.
- [Close-up](02-close-up.png): brighter, tighter composition.
- [Heading space](03-heading-space.png): room on the left for a heading added in the page layout.

These are AI-edited editorial images. Use the guide's pin table for wiring instructions. The guide's displayed image has not been changed; these files are alternatives for selection.
