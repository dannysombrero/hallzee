Bluetooth firmware updates

- Reports the running firmware version and build in Device settings.
- Adds signed firmware package installation over Bluetooth.
- Requires the one-time OTA USB setup before wireless updates are enabled.
- Preserves pairing, terminal settings, and trip records during ordinary updates.
- Accepts trimmed 1–24 character terminal names with common printable punctuation;
  commas remain unsupported because they separate protocol fields.

Physical OTA verification on Windows and macOS is required before publishing a production release.
